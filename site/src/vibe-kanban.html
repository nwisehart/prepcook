Prepcook and vibe-kanban

Prepcook is a fork of vibe-kanban by BloopAI, licensed under the Apache License, Version 2.0. Its NOTICE says so: the product includes software developed by BloopAI as vibe-kanban, and the original copyright notices and license headers are retained in the files that carry them. Prepcook's own changes are under the same license.

This page says what Prepcook took from where it started and what it added. It describes vibe-kanban only as the starting point; for what vibe-kanban is today, see its repository.

What it keeps

The local board: cards in columns, served by a native server on your machine. Sessions that run each attempt in a git worktree of its own. The coding-agent executors, one per agent, that start each agent's session and read back what it did. The remote board service that holds the board in Postgres and streams it to the UI. The single-user model, in which everything that reaches the server on localhost is the board's owner.

What it adds

The method: a fixed order of Plan, Execute, Review and Shipped, worked by the stage orchestrator from a playbook per stage. Plan reproduces the bug first and then writes a root-cause analysis that a person approves before any fix is made; the review runs in a fresh worktree without the planning context.

The knowledge store and the root-cause graph, which keep every approved analysis and open a pattern review when a cause keeps coming back. The integration areas (ticketing, notifications, evidence, reproduction and agents), each built as a factory of providers and configured from Settings (the factory pattern), with the per-repository scripts that stand an app up for a reproduction.

Investigation cards and the card API that files them, which Tammy, the Slack agent in front of Prepcook, is built on. A board with nothing to sign in to: the server signs each request to the board with an owner token.
